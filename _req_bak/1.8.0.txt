添加歌词编辑、制作界面（新文件 lyric_editor.py，模块化）

（原始需求）
接下来，你需要修改以下内容：
1.添加歌词编辑、制作界面（新文件，模块化）
  I.入口
    在歌词选项的重置按钮左侧添加按钮“编辑歌词”
  II.主区域
    在现有的歌曲选择区，即文件夹列表、歌曲选择、信息显示部分叠加frame
  III.样式
    ┌───────────┬─────────────────────────────┐
    │           │                             │ A:时间戳显示区，显示为**:**.***
    │           │                             │ B:歌词显示区
    │           │                             │ C:操作区（操作|键绑定）
    │           │                             │   a:添加行（在选中行上方）
    │           │                             │   b:上一句|↑,W
    │     A     │              B              │   c:打轴|F,J
    │           │                             │   d:下一句|↓,S
    │           │                             │   e:删除行
    │           │                             │   f:撤销|Z
    │           │                             │   g:导入
    │           │                             │   h:完成|ESC
    │           │                             │   i:导出
    ├───────────┴─────────────────────────────┤   j:重做|Y
    │     ┌─────┬─────┬─────┬─────┬─────┐     │
    │     │  a  │  b  │  c  │  d  │  e  │     │
    │     ├─────┼─────┼─────┼─────┼─────┤     │
    │     │  f  │  g  │  h  │  i  │  j  │     │
    │     └─────┴─────┴─────┴─────┴─────┘     │
    │                    C                    │
    └─────────────────────────────────────────┘
  IV.部分说明
    当c时，应记录时间并立即跳转到下一行
    当g时，选择的文件类型为txt,lrc，并检查是否为前缀歌词类型，如果不是，询问是否要进行转换

（设计确认，经询问）
① 布局：上半两栏 [A | B]，下半按钮网格（a~j 两行五列）；图中右侧说明文字仅为图例。
② A 区：上方大字=当前播放时间（实时），下方小字=选中行时间戳（未打轴 --:--.---）。
③ 文本编辑：双击行内联编辑（Enter 确认 / Esc 取消）。
④ 完成：关闭前询问（有歌曲→是否保存到同名 .lrc；无歌曲→是否导出）。
⑤ 打轴到末行：停留（重复打轴覆盖）；已有时间戳直接覆盖。
⑥ 前缀歌词：目标为逐字（前缀展开）格式；导入普通整行歌词时询问是否展开转换。
⑦ 导出：三位毫秒 [mm:ss.xxx]；未打轴行以 [00:00.000] 占位。
⑧ 按钮文字：操作名+键位（如“上一句 ↑W”“打轴 FJ”）。
⑨ 打开编辑器时若歌词非逐字型，同样询问是否展开（与导入一致）。
⑩ 编辑器内不额外提供播放按钮（用主窗口 Space 控制）。

（实现说明）
① 新模块 `lyric_editor.py`（自包含；app 懒创建实例 `app.lyric_editor`）：
   纯逻辑辅助（可单测）——`expand_prefix_lines`（与 LRC-TRANS 一致：按空格分词、
   逐字递增、全角空格填充）、`is_prefix_expanded`（相邻行前缀关系，与 app 主干行判定
   一致）、`fmt_time` / `fmt_lrc_time`（毫秒三位、进位安全）、`parse_lines`（逐行解析，
   保留无时间行、跳过空行与 [offset:]）。
② 入口：「编辑歌词」按钮加入歌词选项标题行（`lyric_edit_btn`，位于「重置」左侧）；
   `app._open_lyric_editor()` 懒创建并以 `place` 将面板叠加在歌曲选择区
   （`bottom_frame`；打开前 `_ensure_bottom_shown` 确保区域可见）。
③ 面板：A 列（当前时间等宽大字 + 选中行时间戳小字）｜B 列（Listbox + 滚动条，
   行格式「时间戳  文本」，选中高亮、自动滚动跟随）｜底部两行五列按钮网格
   （操作名+键位：添加行 / 上一句 ↑W / 打轴 FJ / 下一句 ↓S / 删除行 / 撤销 Z /
   导入 / 完成 ESC / 导出 / 重做 Y）。
④ 十项操作：添加行（选中行上方插入空行）｜上一句/下一句（↑/↓ 在列表控件层拦截，
   W/S 在 root 绑定）｜打轴（记录 `app._current_time()` 到选中行→跳下一行，
   末行停留覆盖）｜删除行｜撤销/重做（全表快照，上限 50）｜导入（txt/lrc；
   非逐字型询问是否展开；展开时原行时间戳复制到所有子行）｜完成（询问保存；
   有歌曲→写回同名 .lrc 并 `_load_lrc_file` 刷新主界面；无歌曲→询问导出）｜
   导出（另存为，未打轴 [00:00.000] 占位）。
⑤ 双击内联编辑：Entry 覆盖行（Enter 提交 / Esc 取消 / FocusOut 提交 / 空格手动插入
   并 break 防触发主窗口播放）；编辑期间快捷键忽略；变更记入撤销栈。
⑥ 快捷键：打开期间绑定 root（W/S/F/J/Z/Y/ESC，关闭解绑；编辑中忽略），
   Listbox 上绑定 ↑/↓（返回 break 防与原生移动双重触发）；ESC 完成。
⑦ A 区 100ms 定时刷新（`after`，关闭时取消），时间显示用等宽字体防跳动/截断。
⑧ 版本 1.8.0；验证 77 项自动化断言（纯逻辑 / 入口 / 覆盖 / 按钮网格布局 /
   载入询问 / 打轴 / 增删 / 撤销重做 / 文本编辑 / 导入三种 / 导出 / 完成四种 /
   快捷键绑定解绑 / A 区显示）+ 布局截图核查 + `python main.py` 冒烟。

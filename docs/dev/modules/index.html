    文件与函数说明

    main.py（入口）

    main() -> None
    • 先 os.chdir(脚本所在目录)，保证相对资源（_internal、Mp.ico）可加载。
    • 创建 tk.Tk() 根窗口，实例化 LrcPlayerApp。
    • root.protocol("WM_DELETE_WINDOW", app.on_close)：点关闭按钮时走 on_close 清理音频资源。
    • 进入 root.mainloop()。

    app.py（主应用，唯一大文件）

    全局常量

    常量 值 用途
    BG_COLOR #23272E 主背景色
    FG_COLOR #C8C8C8 主前景（文字）色
    ACCENT_COLOR #6FA3FF 强调色（高亮/激活）
    SUBTLE_COLOR #3A3F46 次级背景（按钮、状态栏）
    BUTTON_WIDTH 11 主按钮宽度（字符）
    TICK_INTERVAL_MS 10 _tick 定时器间隔
    PLAY_MODES 4 种模式 (显示名, 内部名)：列表循环 / 单曲循环 / 仅一首 / 随机播放
    AUDIO_EXTENSIONS .mp3 .wav .ogg .flac 扫描文件夹时识别的扩展名

    class LrcPlayerApp 方法（按代码分区）

    初始化与构建

    方法 作用
    __init__(root) 设置图标/标题/背景/最小尺寸；初始化全部状态字段；调 _configure_style + _build_ui；后端不可用时弹警告并禁用控件；非 sounddevice 后端禁用倍速/保音高控件；启动 _tick 定时器与快捷键绑定
    _pick_font(family, size, weight) 按名查找系统字体，找不到降级 Segoe UI / TkDefaultFont
    _configure_style() 配置 ttk 样式：clam 主题、LRC.Horizontal.TScale、LRC.Vertical.TScrollbar
    _build_ui() 总布局：左栏（歌词头 + 两行按钮 + 取消条 + 进度条 + 底部面板）+ 右栏（固定 260px）+ 底部状态栏
    _build_status_bar() 底部 24px 状态栏四段（各带悬停提示）：程序状态 / 音频信息 / 歌曲统计 / 插播统计
    _setup_keyboard_shortcuts() 全局键盘快捷键（已移除 Alt）：Space 播放/暂停、F11 全屏
    _toggle_fullscreen() 切换 -fullscreen 属性

    布局子方法

    方法 作用
    _build_header(parent) 左栏顶部：当前歌词行 + 音频/歌词信息行
    _build_button_rows(parent) 两行×5 个按钮，存入 _btn_container 供取消条覆盖
    _build_progress_bar(parent) 进度条 + 右侧时间标签，绑定拖拽取消事件
    _build_bottom_panels(parent) 歌曲列表 / 分隔线 / 歌曲信息条（右三栏定宽 + 悬停提示）
    _build_right_column(parent) 右栏：按钮区 A、插播列表、封面
    _build_operation_area(parent) 右侧操作区：倍速区（含保音高开关）+ 音量区（文字+滑块+取消机制）+ 高级功能区（歌词偏移/声道平衡/响度增益）
    _on_speed_press/_changed/_release 倍速滑块：按下显示取消条 / 拖动仅预览（0.05 步进）/ 松开取消则回退否则应用
    _on_vol_press/_changed/_release 音量滑块：同倍速逻辑，1% 步进
    _toggle_pitch_fix() 切换保音高（变速不变调）模式
    _build_adv_slider(...) 构建一行高级参数滑块（左标题/中滑块/右数值，通用）
    _on_lrc_offset_changed / _on_balance_changed / _on_gain_changed 歌词偏移 / 声道平衡 / 响度增益 回调
    _update_controls_state() 按加载状态统一启用/禁用播放相关控件

    专辑封面

    方法 作用
    _update_cover(path) 提取封面 → 转 PhotoImage → 显示；失败显示占位
    _show_default_cover() 清空图片，显示"无封面"

    插播列表（重要交互区）

    方法 作用
    _refresh_il_buttons() 按状态刷新右栏 A 区按钮文字与命令
    _reset_clear_button() 恢复清除按钮默认状态
    _refresh_interlude_list() 重建 Listbox 显示，保存/恢复滚动位置，同步标题总时长
    _update_interlude_label() 有插播时标题追加总时长 (hh:mm:ss)，无则仅显示"插播列表"
    _on_interlude_select() 移动模式下强制恢复锁定项选中，否则刷新按钮
    _on_interlude_focus_out() 失焦清空选择（移动模式除外）
    _interlude_add() / _interlude_insert() / _interlude_remove() 插播的添加 / 插入 / 删除
    _il_clear_confirm() 二次确认清除插播（3 秒自动恢复）
    _il_enter_move_mode() / _il_move_confirm() 进入 / 退出移动模式
    _il_move_up() / _il_move_down() 上下移锁定项，同步索引并恢复选中
    _ensure_interlude_visible(index) 最小幅度滚动：bbox 定位，仅补足被遮挡部分、不居中

    状态栏更新

    方法 作用
    _read_audio_info() 读当前音频输出设备名（sounddevice 取设备名；pygame：采样率/位深/声道）
    _refresh_status_bar() 刷新歌曲统计与插播统计
    _set_scan_progress(done, total) 扫描进度文字进度条
    _set_status_ready() 扫描完成置"就绪"

    歌曲列表与扫描

    方法 作用
    _scan_folder() 选目录 → 清列表显示扫描占位 → 起后台线程 _scan_thread（不卡 UI）；首次扫描扩窗
    _scan_thread(folder, generation) 后台扫描：枚举路径 → 逐个读元数据+LRC，实时回传进度；排序后 _apply_scan_result 主线程落地
    _apply_scan_result(items, generation) 主线程应用扫描结果，启用上一曲/下一曲，启动时长缓存线程
    _bg_cache_thread(generation) 子线程逐首缓存时长；世代号用于新扫描让旧线程退出
    _on_duration_cached(index, duration) 主线程回调更新信息面板时长
    _song_sort_key(item) (static) 排序键：目录层级 → 专辑 → 音轨号 → 文件名
    _get_metadata(path) (static) mutagen 读 (音轨号, 专辑名, 歌手名)
    _refresh_song_list() 重建歌曲 Listbox
    _on_song_select() 单击 → 更新信息面板，不切歌

    audio_engine.py（音频引擎）

    模块级：

    • _format_size(size_bytes) — 字节 → B/KB/MB/GB 字符串。
    • _get_track_number(path) — 从标签读取音轨号（键名 tracknumber/track/trck）。

    class AudioEngine：

    成员 作用
    __init__ / _init() 优先初始化 sounddevice，失败回退 pygame，置 _ready 与 backend
    ready / current_path (property) 引擎可用性 / 当前加载路径
    samplerate / channels (property) 当前音频采样率 / 声道数
    load(path) sounddevice：打开 soundfile + 建流；pygame：music.load
    play(start=0.0) / pause() / unpause() / stop() 播放 / 暂停 / 恢复 / 停止
    seek(seconds) 设置源采样位置（sounddevice）或 music.play(start)（pygame）
    get_position() 当前源位置（秒）；pygame 返回 None
    is_busy() 是否在播放（曲终检测）
    set_speed / get_speed 倍速 0.1~3.0；pygame 后端不支持
    set_volume / get_volume 音量 0~1；pygame 映射 music.set_volume
    set_pitch_fix / get_pitch_fix 保音高模式开关（仅 sounddevice，内部用 PhaseVocoder）
    get_duration(path) soundfile 读时长（pygame 用 Sound 读）
    get_file_info(path) (static) 拼装基本信息 dict（文件名/格式/大小/音轨号/时长/歌词）
    quit() 释放流与文件 / pygame 资源

    PhaseVocoder（保音高时间伸缩）：STFT + 相位累加，factor = 1/speed；流式 process(x)->y，内部维护输入尾部与重叠相加缓冲，seek/换曲时 reset()。

    lrc_parser.py（歌词解析，纯逻辑）

    class LrcParser：

    • TIME_RE — 匹配 [mm:ss.xx] 或 [mm:ss]。
    • OFFSET_RE — 匹配 [offset:±ms]。
    • parse(text) (classmethod) — 逐行解析：收集 offset → 展开多时间标签 → 换算秒 → 应用 offset → 排序。空歌词以 " " 占位。返回 list[tuple[float, str]]。
